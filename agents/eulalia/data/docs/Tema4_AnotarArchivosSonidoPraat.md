## Página 1

Instrucciones para anotar un archivo de sonido 
 
En Praat podemos usar anotaciones para marcar trozos de un archivo de sonido. Lo usamos 
para saber qué sonidos o palabras aparecen en cada trozo. La siguiente imagen muestra un 
ejemplo: 
 
Para anotar un archivo de sonido, sigue estos pasos: 
1. Abre tu archivo de sonido en Praat 
2. Haz clic en el nombre del archivo (en Praat) y luego haz clic en Annotate, y luego en To 
Text Grid. En el cuadro “All tier names” indica “Silabas” si vas a anotar sílabas, 
“Fonemas” si vas a anotar fonemas, o ambos si anotarás ambos. Luego selecciona Ok.

## Página 2

3. Ahora verás en el cuadro Objects un archivo TextGrid.  Para hacer anotaciones, 
seleccionas el sonido y su textGrid correspondiente y pulsa en View & Edit. 
 
 
 
4. Ahora verás el archivo Para hacer una anotación a un sonido (o grupo de sonidos) 
debes marcar el punto de inicio y fin de dicho sonido.  
a. Busca el punto en que comienza el sonido  
b. Haz clic en ese punto (en el oscilograma) 
c. Pulsa Intro. Una ralla azul indica que has hecho la marca. 
   
 
d. Busca el punto en que termina el sonido 
e. Haz clic en ese punto (en el oscilograma) 
f. Pulsa Intro. Ahora aparecerá otra ralla azul, y porás seleccionar fácilmente tu 
sonido.

## Página 3

g. Si haces clic en la parte de abajo (lo que se ve en amarillo arriba), podrás 
escribir tu anotación 
 
 
5. Una vez hayas hecho tus anotaciones, debes acordarte de guardar tu archivo. Para 
ello, antes de cerrar el sonido, debes seleccionar File – Save TextGrid as text file.  
 
 
Nota: Si cierras el cuadro, también puedes guardar tus anotaciones seleccionándolo en 
la ventaja objetos y seleccionado Save – Save as Text file.

# Ejercicio 2.3. Errores fonológicos (con Solución)

Abajo tienes una lista de palabras (escritas según la ortografía) y una producción incorrecta. Para cada palabra, debes:

-Indicar la transcripción fonológica de la palabra correcta

-Indicar la transcripción fonológica de la palabra incorrecta

-Indicar el o los errores fonológicos cometidos

Nota: asumimos que es un hablante distinguidor, esto es, que sabe diferenciar los fonemas /s/ -/ θ/ 

##  Lista de palabras y transcripción fonológica

1. "meseta” > "beseta”

2. "chilla” > "chicha”

3. "averiguar” > "averigar”

4. "estudiar” > "estudá”

5. "comprar” > "tompar”

6. "encender” > "epenter”

7. "desencuentro”> "senkento”

8. "abrir”> "babir”

9. "caña”> "caya”

10. "cielo”>”felo”


## Solución

1. "meseta” > "beseta”

TF: / me.'se.ta / > / be.'se.ta /

Error sistémico de nasalidad. Desnasalización: m > b

2. "chilla” > "chicha”

TF: / 'ʧi.ʝa/ > / 'ʧi. ʧa/

Error de estructura de palabra. Asimilación regresiva: ʝ > ʧ

3. "averiguar” > "averigar”

TF: / a.be.ɾi.'guaɾ / > / a.be.ɾi.'gaɾ /

Error de estructura de sílaba. Simplificación del núcleo: ua > a

4. "estudiar” > "estudá”

TF: / es.tu.'diaɾ / > / es.tu.'da /

Error de estructura de sílaba. Simplificación del núcleo: ia > a

Error de estructura de sílaba. Omisión de coda: ɾ

5. "comprar” > "tompar”

TF: / kom.'pɾaɾ / > / tom.'paɾ /

Error sistémico de lugar de articulación. Adelantamiento: k > t

Error de estructura de sílaba. Simplificación de ataque: pɾ > p

6. "encender” > "epenter”

TF: / en.θen.'deɾ / > / e.pen.'teɾ /

Error de estructura de sílaba. Omisión de coda: en > e

Error sistémico de lugar de articulación (adelantamiento) y de modo de articulación (pasa de fricativa a oclusiva): θ > p

Error sistémico de sonoridad (ensordecimiento): t > d

7. "desencuentro”> "senkento”

TF: / de.sen.'kuen.tɾo / > / sen.'ken.to /

Error de estructura de palabra. Omisión de sílaba átona: / de /

Error de estructura de sílaba. Simplificación del núcleo: ue > e

Error de estructura de sílaba. Simplificación de ataque: tɾ > t

8. "abrir”> "babir”

TF: / a.'bɾiɾ / > / ba.'biɾ /

Error de estructura de sílaba. Simplificación de ataque: bɾ > b

El error /a/ >/ba/ (en la sílaba inicial) se puede interpretar de dos formas (las dos correctas):

- Error de estructura de sílaba: Inserción
- Error de estructura de palabra. Asimilación.

9. "caña”> "caya”

TF: / 'ka.ɲa/ > / 'ka.ʝa/

Error sistémico de nasalización (desnasalización): ɲ > ʝ

10. "cielo”>”felo”

TF: / 'θie.lo / > / 'fe.lo /

Error sistémico de lugar de articulación. Adelantamiento. θ> f

Error de estructura de sílaba. Simplificación de núcleo. ie > e

**Status:** Terminated (12 February 2025)
**Total cost:** 188,590.08 (funded: 188,590.08) EUR
**Website:** https://cordis.europa.eu/project/id/101109355

## Summary

The project develops a diagnostic tool using impedance spectrum analysis to detect photovoltaic panel failures during operation at maximum power point. It comprises an electronic device and failure classification algorithm. The proposed diagnostic tool will be formed by an electronic device and a failure classification algorithm running on an embedded system.

**Keywords:** Failure classification algorithm, Dynamic model parameters, embedded system design, hardware implementation, experiments with different technologies

# iGame: Multi-dimensional Intervention Support Architecture for Gamified eHealth and mHealth Products

**Grant ID:** 823871
**Funder:** European Commission
**Programme:** H2020 — Marie Sklodowska-Curie Actions (MSCA-RISE)
**Period:** 2019-01-01 — 2024-06-30
**Status:** Closed
**Total cost:** 837200 (funded: 837200) EUR
**Website:** https://cordis.europa.eu/project/id/823871
**Project website:** https://h2020-igame.eu/

## Summary

The iGame project investigates evidence-based gamification techniques for eHealth and mHealth, developing an architectural platform to improve the efficacy of gamified health solutions. The project creates advanced game production techniques with ready-to-use toolkits to accelerate the innovation process for digital health products. Outcomes include gamification toolkits, an integrated ICT platform, and clinical assessment methodologies evaluated through physical activity interventions in primary care settings with the Servicio Andaluz de Salud (Andalusian Health Service).

**Keywords:** Gamification, eHealth, mHealth, Digital Health, Physical Activity, Primary Care, Health Interventions

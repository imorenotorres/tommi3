Crea pseudopalabras

Una pseudopalabra es una expresión que se parece fonológicamente a una palabra real, pero que no tiene significado. Tu tarea es crear una pseudopalabra a partir de la palabra que se te presenta.

¿Cómo crear una buena pseudopalabra? Debe cumplir estas condiciones:
  • No ser una palabra real del español.
  • Respetar las reglas fonotácticas del español (que suene como si pudiera ser una palabra del español).
  • Tener el mismo número de sílabas que la palabra original.
  • Que cada sílaba tenga la misma complejidad (p.ej., si la original tiene una sílaba CCV como «bro», la pseudopalabra debe tener también una sílaba CCV en esa posición, como «pli»).
  • Tener el acento en la misma sílaba que la palabra original (p.ej., si la original es llana, la pseudopalabra también debe ser llana).
Ejemplo: mesa (CV.CV, llana) → tesa (CV.CV, llana). Ejemplo incorrecto: mesa → trán (distinto número de sílabas, distinta complejidad).
Nota: El sistema comprueba automáticamente las reglas fonotácticas y detecta muchas palabras reales, pero no conoce todas las palabras del español. Asegúrate tú mismo de que tu pseudopalabra no es una palabra real (puedes buscarla en un diccionario si tienes dudas).

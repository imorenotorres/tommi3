Reliability of Query Classification in RAG Agents

A Controlled Comparison of Rule-Based and LLM-Based Approaches

Research Context

AI-powered educational assistants are increasingly deployed in universities to support students, researchers, and faculty. The EU AI Act (Regulation EU 2024/1689) classifies AI systems used in education as high-risk, noting that they "may determine the educational and professional course of a person's life." In this context, reliability is not a desirable feature but a prerequisite: an unreliable assistant risks propagating misinformation in a setting designed to build understanding.

This research project investigates how to build reliable AI agents for education, using the UNINOVIS European university alliance (8 universities across 8 countries) as a testbed. The agents serve as research assistants specialised in Responsible AI, helping users search papers, look up researchers, explore projects, and answer conceptual questions.

Reliability is evaluated using the four-dimensional framework proposed by Rabanser et al. (2025): consistency (same query, same response), robustness (handles diverse phrasings), predictability (knows when it might be wrong), and safety (refuses out-of-scope queries).

Study Aim

A key architectural decision in building reliable RAG agents is how to classify user queries to route them to specialised response paths. Some paths bypass the LLM entirely (producing deterministic, hallucination-free responses from structured data), while others use the LLM with targeted context.

This study compares the reliability of three approaches to query intent classification:

Production rule-based — hand-crafted patterns developed over months of real-world use
Auto-constructed rule-based — broad patterns built automatically through batch feedback
Auto-constructed LLM-based — a separate LLM call classifies the query before response generation

All three approaches share identical response paths — the only difference is how the classification decision is made. This isolation allows us to attribute reliability differences to the classification mechanism itself.

A Baseline (vanilla RAG with no classification) establishes the case for classification: it achieves 0% response consistency and 10% refusal accuracy, demonstrating that classification is necessary for reliability in high-stakes domains.

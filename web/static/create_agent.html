Reliability Badges

Configure the thresholds for reliability badge colours. The system checks what percentage of the response comes from the LLM (ungrounded content) and assigns a badge accordingly.
Responses with LLM content at or below this % get a green badge
Responses with LLM content at or above this % get a red badge
Values between green and red thresholds produce a yellow (Good) badge. These can be changed later in config.json.

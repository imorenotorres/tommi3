RAG Architecture Study

How does each architectural layer affect AI agent reliability?

Research Question

This study compares four agent architectures to measure the effect of metadata, reasoning method, and classification approach on reliability — measured across consistency, robustness, correctness, predictability, and safety (Rabanser et al., 2025).

All variants share the same LLM (Mistral), the same BM25 retrieval, and the same Responsible AI domain. Each variant adds exactly one architectural layer. Click any variant to see details and hypotheses.

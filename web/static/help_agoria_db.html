Asistente BD Algoria

Este asistente permite consultar la base de datos de convenios de movilidad universitaria mediante lenguaje natural. Traduce tus preguntas a consultas SQL, las verifica y devuelve los resultados directamente de la base de datos.

¿Qué puedes preguntar?

  • Buscar convenios por universidad, país o región
  • Filtrar por requisitos de idioma, nivel de estudios (grado, máster, doctorado)
  • Consultar plazas disponibles, tutores o requisitos académicos
  • Buscar convenios por facultad, código ISCED o programa de movilidad

Nota: Los datos de la base de datos están en inglés. Para obtener mejores resultados, usa los nombres de universidades y países en inglés (puedes añadirlos entre paréntesis).

Ejemplos de consultas

¿Qué convenios hay con The Hague University of Applied Sciences?
¿Qué universidades de los Países Bajos (Netherlands) tienen convenios?
¿Hay convenios con requisito de 'English B1'?
¿Tenemos convenios con Alemania (Germany)?

Tipo de agente

Este es un agente de tipo Text-to-SQL: cuando haces una pregunta, el modelo de lenguaje (LLM) genera una consulta SQL que se ejecuta contra la base de datos relacional. A diferencia de un agente RAG, los resultados provienen directamente de la base de datos, no de un resumen generado por IA.

El proceso es:

  1. Interpretación — El LLM traduce tu pregunta a una consulta SQL
  2. Verificación — La consulta SQL se valida antes de ejecutarse
  3. Ejecución — La consulta se ejecuta contra la base de datos
  4. Presentación — Los resultados se formatean como respuesta legible

Indicadores de fiabilidad

Cada respuesta incluye un indicador de fiabilidad (banner de color) que muestra el origen de la información:

  • Verde — Datos verificados directamente de la base de datos (sin interpretación de IA)
  • Amarillo — La IA interpretó tu pregunta como la consulta SQL mostrada. Comprueba que coincide con tu intención
  • Rojo — Contenido generado por IA sin datos de la base de datos. Verificar de forma independiente

Transparencia

Los iconos en la barra lateral muestran la configuración del agente:

Caja de cristal — El agente muestra la consulta SQL generada y los detalles de verificación. Máxima transparencia.
Indicadores de fiabilidad activados — Los banners de color están visibles en cada respuesta.

El icono 🟢 indica que el nivel de prompt es estricto: el agente rechaza consultas SQL no verificadas y muestra advertencias.

Limitaciones

  • La IA genera la consulta SQL — puede interpretar mal tu pregunta. Revisa siempre la consulta SQL mostrada en el banner amarillo.
  • Los nombres de universidades, países y campos están en inglés. Usa los nombres en inglés para mejores resultados.
  • El agente no puede responder preguntas que no se resuelvan con una consulta SQL (opiniones, recomendaciones, comparaciones cualitativas).

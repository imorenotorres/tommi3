Agent type & LLM provider: ?

Agent type — The architecture used by this agent:
• RAG — Searches a document database and answers from retrieved context.
• Metadata+RAG — Like RAG plus structured metadata (authors, universities, topics), maps and figures.
• Text2SQL — Converts questions into SQL queries against a relational database.
• Oneshot — Single LLM call with no document retrieval.
The agent type is set when the agent is created and cannot be changed afterwards.

LLM provider — The language model service. Can be changed in the .env file (LLM_PROVIDER = ollama or mistral).

Agent tuning: ?

LLM — Select the language model. Click to cycle through available models.
Transparency — Controls how much detail is shown about response reliability. Crystal box = full detail, Grey box = minimal, Black box = none.
Prompt — Controls how strictly the system prompt constrains the LLM. Stringent = all rules enforced, Tolerant = standard rules only, Lax = identity only.

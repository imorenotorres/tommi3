Agent type — The architecture used by this agent:
• RAG — Searches a document database using vector embeddings and answers from retrieved context.
• Metadata+RAG (Vector) — Like RAG plus structured metadata (authors, universities, topics), maps and figures. Uses vector embeddings for document search.
• Metadata+RAG (Vectorless) — Same as Metadata+RAG but uses keyword-based BM25 retrieval instead of vector embeddings. No ChromaDB dependency.
• Text2SQL — Converts questions into SQL queries against a relational database.
• Oneshot — Single LLM call with no document retrieval.
The agent type is set when the agent is created and cannot be changed afterwards.

Prompt
• Stringent: all prompt rules enforced. The agent is constrained to use only curated database content. LLM involvement is minimal.
• Tolerant: standard rules only. The agent uses curated data but the LLM interprets and connects it.
• Lax: identity only. The agent can freely use all data sources including unconstrained LLM generation.

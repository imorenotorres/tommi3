1 What is Sonic Composer?

Sonic Composer is an interactive music agent that lets you create and modify music in real time using natural language. You describe what you want to hear, and the agent generates Sonic Pi code and plays it immediately.

The interaction is incremental: the music keeps playing in a loop, and each new instruction modifies what is currently sounding — you can add instruments, change tempo, switch scales, apply effects, or remove elements, all without stopping the music.

No programming or music theory knowledge is required. You can interact via natural language in the chat, via the control panel, or a combination of both.

2 Requirements

  • Sonic Pi 4.x installed and running on your machine (download here)
  • TOMMI Lite running locally
  • psonic Python library (for communication with Sonic Pi)

Install the Python dependency:

pip install python-sonic
Tip: Sonic Pi must be open before you start the agent. The agent automatically detects Sonic Pi's connection parameters at startup.

3 Setup

Step 1: Open Sonic Pi and wait until it finishes booting (you should see the editor ready).

Step 2: Start TOMMI Lite as usual:

python app.py

Step 3: Select Sonic Composer from the agent list in the sidebar.

That's it. The agent automatically reads the connection parameters (token, ports) from Sonic Pi's log file at ~/.sonic-pi/log/gui.log. No manual configuration is needed.

Important: Sonic Pi assigns new ports and a new token every time it restarts. If you restart Sonic Pi, you must also restart TOMMI Lite so the agent picks up the new values.

Manual configuration (only if auto-detection fails):

Edit agents/sonic_composer/env.txt and set the values manually:

SONIC_PI_HOST=127.0.0.1
SONIC_PI_TOKEN=<your_token>
SONIC_PI_GUI_PORT=<gui_port>
SONIC_PI_OSC_PORT=<spider_port>

To find the current values:

strings ~/.sonic-pi/log/gui.log | grep "daemon_stdout"

The output shows 8 numbers in order. You need:

PositionValueVariable
2ndGUI portSONIC_PI_GUI_PORT
3rdSpider portSONIC_PI_OSC_PORT
8thTokenSONIC_PI_TOKEN

4 Control panel

When you select Sonic Composer, a control panel appears between the top bar and the chat area. It provides quick access to the most common parameters without typing.

Panel controls

ControlDescription
BPMSlider (40–200) to set the tempo
SynthDropdown to select the synthesizer sound
ScaleDropdown to select the musical scale
LoopDropdown to select a pre-recorded loop sample
FXCheckboxes to enable/disable effects (reverb, echo, etc.)
ApplyBuilds a natural language instruction from the selected parameters and sends it to the agent
StopStops all music

Active loops

The Active section shows all loops currently playing. Each loop is displayed as a tag that you can click to mute or unmute:

  • ▶ name (purple background) — loop is active. Click to mute it.
  • ◼ name (grey background, strikethrough) — loop is muted. Click to reactivate it.

Muting sets the loop volume to zero without removing it from the composition, so you can bring it back at any time.

Tip: You can combine the control panel with chat instructions. For example, set the BPM and synth in the panel, then type more specific instructions in the chat like "make the melody more spacious with echo".

5 How to use it

Type what you want to hear in natural language. The agent understands instructions in English and Spanish. Here's the basic workflow:

  1. Start the music: Describe what you want to hear
    "Play a calm piano melody in C major"
  2. Modify in real time: Give instructions to change what's playing
    "Make it faster", "Add a bass line", "Switch to minor scale"
  3. Add layers: Each instruction can add new elements on top of what's already playing
    "Add a techno beat", "Add reverb to the melody"
  4. Mute/unmute: Click on active loops in the panel to toggle them on or off
  5. Stop everything: Click the Stop button or say "Stop"

Code diff

After each instruction, the generated Sonic Pi code is displayed in a highlighted box. When the code changes, you can see exactly what was modified:

  • Green bullet — new or modified line
  • Red bullet with # — removed line (shown in the position where it was)

This makes it easy to understand what changed and is also a great way to learn Sonic Pi syntax.

Pan (stereo positioning)

You can position sounds in the stereo field:

  • pan: -1.0 = full left
  • pan: 0.0 = center (default)
  • pan: 1.0 = full right

Example: "Put the melody to the right and the bass in the center"

Generative music

Generative loops play random notes from a scale, creating different patterns each cycle. You can control:

  • density — how many notes per cycle (e.g. 4 for sparse, 16 for dense)
  • sleep_range — how spaced the notes are (e.g. [0.1, 0.3] for fast, [1.0, 3.0] for slow)
  • num_octaves — range of notes (1 for focused, 3–4 for wide)

Example: "Add something generative with hollow in pentatonic, density 4, slow and spacious, with reverb and echo"

7 Example sessions

Creating a chill track step by step

You: "Play a slow piano melody in C major at 80 bpm"

A calm piano melody starts playing in C major.

You: "Add a soft bass with the FM synth"

A bass line joins the melody, playing low notes with the FM synthesizer.

You: "Add reverb to the piano"

The piano melody now sounds spacious with reverb applied.

You: "Add a gentle hip-hop beat"

A hip-hop drum pattern starts playing alongside the melody and bass.

You: "Switch everything to A minor"

The melody and bass shift to A minor, giving a darker mood. The code diff shows the changed note arrays in green.

You: [Click on the beat loop tag to mute it]

The beat is muted (volume 0) but remains in the composition. Click again to unmute.

You: "Stop"

All sounds stop.

Ambient / generative soundscape

You: "Create a generative soundscape with hollow in pentatonic, density 4, with reverb and echo, at 60 bpm"

Random pentatonic notes with hollow synth, spacious and slow.

You: "Add a slow bass drone with dsaw in C2, volume low, with reverb"

A deep drone joins the generative melody.

You: "Add the safari loop at half speed, volume low, positioned to the left"

Slowed-down African percussion panned to the left adds a textural layer.

You: "Make the generative melody more spacious, with notes further apart"

The sleep range increases, making the melody more sparse and contemplative.

Quick one-liners

You: "Techno beat at 135 bpm with a tb303 bass and echo"

A complete techno track starts immediately.

You: "Play the amen break at half speed with lots of reverb"

The classic breakbeat slowed down into an atmospheric texture.

You: "Play the bass line from With or Without You by U2 with FM synth"

D, A, B, G bass pattern at ~110 bpm.

Using the control panel

You: [Set BPM to 90, select "hollow" synth, select "pentatonic" scale, check "reverb" and "echo", click Apply]

The panel composes the instruction automatically and sends it. Music starts with the selected parameters.

You: [Select "loop_tabla" from the Loop dropdown, click Apply]

Indian tabla percussion is added to the existing composition.

You: [Click the tabla loop tag to mute it]

Tabla is silenced. Click again to bring it back.

8 Troubleshooting

ProblemSolution
"Sonic Pi no conectado" Make sure Sonic Pi is open and fully booted before starting TOMMI Lite. If you opened Sonic Pi after starting TOMMI Lite, restart TOMMI Lite.
"No se pudieron detectar los parámetros" The auto-detection reads ~/.sonic-pi/log/gui.log. If this file doesn't exist, Sonic Pi may not have been started yet. Open Sonic Pi, wait for it to boot, then restart TOMMI Lite.
Agent responds but no sound Check that Sonic Pi's volume is up and audio output is configured. Try running play 60 directly in Sonic Pi to verify it works.
Sound doesn't change after instruction Sonic Pi's live_loop waits for the current cycle to finish before applying changes. Wait a few seconds for the loop to restart.
Connection lost after restarting Sonic Pi Sonic Pi assigns new ports on each restart. Restart TOMMI Lite so the agent re-detects the new parameters.
psonic import error Install the dependency: pip install python-sonic
Control panel not visible The panel only appears when the Sonic Composer agent is selected. Select it from the sidebar.

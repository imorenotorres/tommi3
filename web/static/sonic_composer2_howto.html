1 What's new in v2?

Sonic Composer v2 is a style-aware music agent that understands musical genres and their characteristic patterns. It builds on v1 with these improvements:

  • Intent classification NEW — The agent understands what kind of request you're making (new composition, modify, add element, remove, stop, or ask for info) and handles each one differently
  • Style presets NEW — 10 built-in musical styles with authentic drum patterns, chord progressions, and instrument choices (rock, blues, jazz, techno, house, ambient, bossa nova, reggae, hip-hop, lo-fi)
  • Resource validation NEW — All synths, samples, scales, and effects are validated against Sonic Pi's actual resources — no more hallucinated instrument names
  • Programmatic modifications NEW — Simple changes (BPM, synth, scale, effects) are handled directly in code without calling the LLM, making them instant and reliable
  • Sonic Pi Bridge NEW — Optional bridge for playing through Sonic Pi locally, with Strudel as browser fallback
  • Recording NEW — Record your composition and download as WAV (requires bridge)
  • Panel sync — The control panel updates automatically to reflect what's playing
  • Code diff — Changed lines are highlighted with green/red bullets
  • Copy button — Copy the generated Sonic Pi code to paste into Sonic Pi directly

2 Audio modes

Sonic Composer v2 supports two audio modes:

Sonic Pi (via Bridge) — recommended

Plays through your local Sonic Pi installation. You hear the real Sonic Pi sounds. Requires running the bridge script alongside Sonic Pi.

The status indicator in the panel shows ● Sonic Pi when connected.

Strudel (browser fallback)

Plays directly in the browser using Web Audio. No installation needed, but the sound quality is lower (uses oscillators instead of Sonic Pi's rich synths).

The indicator shows ● Strudel when using browser audio.

Tip: The agent automatically detects which mode is available. If the bridge is running, it uses Sonic Pi. If not, it falls back to Strudel. No configuration needed.

3 Setup

Browser only (Strudel) — zero setup

Just open the Sonic Composer v2 page. Sound plays in your browser.

With Sonic Pi (recommended)

  1. Open Sonic Pi and wait until it finishes booting
  2. Double-click start_bridge.command (Mac) or start_bridge.bat (Windows)
    First time: it creates a virtual environment and installs dependencies automatically
  3. Open the Sonic Composer v2 page in your browser
  4. The indicator should show ● Sonic Pi
Important: If you restart Sonic Pi, restart the bridge too — the connection parameters change on each restart.

7 Recording

You can record your composition and download it as a WAV file. This feature requires the Sonic Pi bridge.

  1. Make sure the indicator shows ● Sonic Pi
  2. Start your music
  3. Click ● Rec to start recording
  4. The button changes to ■ Stop Rec
  5. When done, click Stop Rec
  6. The WAV file downloads automatically
Tip: The Rec button only appears when the Sonic Pi bridge is connected.

8 Example sessions

Exploring styles

You: "Play a rock and roll riff"

Rock shuffle drums, distorted guitar riff in E, tb303 bass at 140 BPM.

You: "Un poco más lento"

BPM drops by 10 (instant, programmatic). Everything else stays the same.

You: "Stop"

All sounds stop.

You: "Toca un blues en Mi"

Blues shuffle at 90 BPM with piano blues scale, walking bass in E, triplet feel drums.

You: "Stop. Make a jazz piece"

Cool jazz at 110 BPM with ride cymbal, Dm7-G7-C-Am7 piano voicings, walking bass.

Modifying with the panel

You: "Create a chill lo-fi beat"

Lo-fi at 75 BPM. Panel updates: BPM=75, Synth=piano, FX: reverb+echo checked.

You: [Move BPM slider to 85, click Apply]

BPM changes to 85. Everything else unchanged (programmatic).

You: [Click on bass loop tag to mute it]

Bass is silenced. Click again to unmute.

Asking for info

You: "What styles do you know?"

Lists all 10+ styles with descriptions (no music plays — info intent).

You: "What synths are available?"

Lists all valid Sonic Pi synths with descriptions.

Recording a composition

You: "Make a bossa nova"

Bossa nova starts playing through Sonic Pi.

You: [Click Rec button]

Recording starts. Button turns red.

You: "Add reverb to everything"

Reverb added (programmatic). Still recording.

You: [Click Stop Rec]

Recording stops. composition.wav downloads.

9 Troubleshooting

ProblemSolution
No sound at all If using Strudel: check browser volume and try clicking on the page first (audio context needs user interaction). If using bridge: make sure Sonic Pi is open and the bridge is running.
Indicator shows ● Strudel but I want Sonic Pi Start the bridge: double-click start_bridge.command. The indicator updates automatically.
Bridge was working but stopped You probably restarted Sonic Pi. Restart the bridge too.
Agent changes too much when I modify Use specific instructions: "change BPM to 90" instead of vague requests. Simple changes (BPM, synth, scale, fx) are handled programmatically and never change other elements.
Invalid chord names in code v2 validates and auto-corrects common hallucinations (e.g. "Caj3" → "C"). If you spot an issue, try again.
Rec button not visible Recording requires the Sonic Pi bridge. Start the bridge and the Rec button appears.
WAV file is empty or doesn't download Make sure music is playing when you click Rec, and wait a few seconds before clicking Stop Rec.
Panel doesn't update after response Reload the page. The panel syncs on each new response.

🐍 Python Practice

Interactive Python coding exercises — runs entirely in the browser, no installation required

What this tool does

Python Practice lets students write and run real Python code directly inside Moodle. Teachers create exercise banks with automatic test cases; students get instant pass/fail feedback on every attempt. No server execution is involved — Python runs locally in the student's browser via Pyodide (WebAssembly).

  • Full Python 3 environment in the browser — for, def, class, standard library
  • Syntax highlighting editor (CodeMirror) with keyboard shortcut Ctrl+Enter to run
  • Automatic test runner: each exercise has test cases with expected outputs
  • Stdout capture — print() statements are shown in the output panel
  • Optional hints per exercise, revealed one by one on demand
  • Progress tracked per student — completed exercises marked with ✓ in the sidebar
  • No LLM — all execution and grading is fully client-side

For teachers — creating exercises

  1. Launch the tool from your Moodle course (you must be enrolled as instructor)
  2. Click + Añadir in the sidebar
  3. Fill in the title, difficulty, description, and starter code
  4. Add test cases: each test is a Python expression and its expected output (as a string). For example, expression suma(1, 2) → expected 3
  5. Optionally add hints that students can reveal one at a time
  6. Click Guardar — the exercise is immediately available to students
Test format: The expression is evaluated with Python's eval() and the result compared as a string via str(). Boolean results must be written as True / False (capital first letter). List results must match Python's default repr exactly, e.g. [1, 2, 3] (with spaces after commas). Use the Try it link on this page to test your exercises as a student.

For students — using the tool

  • Select an exercise from the sidebar
  • Read the description and write your solution in the code editor
  • Press ▶ Ejecutar (or Ctrl+Enter) to run your code against the test cases
  • Each test shows whether it passed (green ✓) or failed (red ✗) with the obtained vs expected value
  • Use 💡 Pista to reveal hints one at a time if you get stuck
  • Use ↺ Restablecer to restore the original starter code
  • Once all tests pass, the exercise is marked as completed in the sidebar
Note: Python loads in the background when you first open the tool (you will see "Cargando Python…" in the top-right corner). Wait for "Python listo" before running code.

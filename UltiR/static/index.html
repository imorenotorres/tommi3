Ready-to-use LTI tools for Moodle

UltiR is a shared repository of learning tools built by the UNINOVIS alliance. Each tool can be embedded directly into any Moodle course as a native activity — no extra logins for students, no software to install for teachers.

🔌

Plug and play

Register once in Moodle, add to any course. Students launch with a single click.

🎓

Built for teaching

Tools designed by teachers for teachers — practice exercises, AI-assisted projects, writing feedback.

🔒

Per-course isolation

Each course gets its own data space. Multiple courses can use the same tool without interference.

Explore the available tools in the Repository tab, or check the Technical Information for Moodle setup instructions.

For Moodle administrators

How to register a tool (one-time setup)

Each tool needs to be registered once at the site level. After that, any teacher can add it as an activity in their course.

  1. Go to Site administration → Plugins → Activity modules → External tool → Manage tools
  2. Click Configure a tool manually
  3. Fill in the fields using the values from the table below for the tool you want to register
  4. Under Tool configuration usage, select Show in activity chooser and as a preconfigured tool
  5. Under Default launch container, choose Embed (recommended) or New window
  6. Save changes

Important: The consumer key and shared secret must match exactly between Moodle and the server. Contact the UNINOVIS ICT team if you do not have them.

For teachers

How to add a tool to your course

Once a tool is registered by the administrator, you do not need any credentials. Simply:

  1. Go to your course and click Add an activity or resource
  2. Select External tool and choose the preconfigured tool (e.g. FonESP)
  3. Save — the tool appears as a regular activity in the course

When a student clicks the activity, Moodle handles authentication automatically. The tool receives the student's name, email, role, and course ID — no separate login is needed.

How LTI works

LTI (Learning Tools Interoperability) is an open standard that lets external tools integrate with Moodle as if they were native activities. Each tool is registered once with a consumer key and shared secret. Moodle signs each launch request with OAuth 1.0a, so the tool can verify the user's identity and role without requiring a separate login.

Each course gets its own independent data space, so multiple courses can use the same tool without interference. The tool automatically detects whether the user is an instructor or a student and shows the appropriate view.
